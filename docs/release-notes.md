# 公开版发布说明

## 本次发布包含

- 本地论文审稿工作台的完整前后端代码
- `docx` / `pdf` 论文解析能力
- 自定义规则管理与审稿规则叠加
- 阿里云百炼兼容接口接入
- 审稿报告查看、论文与意见对应查看
- Markdown / PDF / Word 批注版导出
- 项目 Logo、README 和页面截图

## 本次发布默认不包含

- 真实论文原文
- 用户本地解析结果、审稿结果和导出结果
- 阿里云百炼 API Key 等敏感配置
- 本地测试样本、临时导出文件、调试缓存

这些内容默认通过 `.gitignore` 排除，避免误提交到公开仓库。

## 建议使用方式

1. 克隆仓库后，先按 `README` 安装依赖并启动本地服务。
2. 首次使用时，在页面中配置百炼接口地址、API Key 和模型参数。
3. 使用测试论文先跑通上传、解析、审稿和导出流程，再接入正式论文。

## 面向公开仓库的维护约定

- 欢迎提交 `Issues` 反馈解析问题、界面问题、模型输出问题和导出问题。
- 欢迎通过 `Pull Requests` 提交功能增强、Bug 修复和文档改进。
- 如果改动影响 UI，建议同时补一张页面截图。
- 如果改动影响导出格式，建议同时说明 Markdown / PDF / Word 三种导出的变化。

## 发布前检查清单

- 确认 `data/` 下没有要公开的内容
- 确认 `data/settings.json` 中没有残留 API Key
- 确认 `.gitignore` 已覆盖本地产物和调试目录
- 确认 `README.md` 中的截图和功能描述与当前代码一致
- 确认至少完成一轮基础检查：

```bash
python3 -m py_compile app.py graduate_review/*.py graduate_review/parsers/*.py
node --check static/app.js
```

## 当前公开版定位

当前仓库更适合作为：

- 本地部署的毕业论文审稿辅助工具
- 百炼 / Qwen 文档审稿类应用参考项目
- 论文解析、规则审查和导出联动的示例工程

后续如果继续迭代，建议优先完善：

- 解析结构稳定性
- 审稿结果定位精度
- 图表与正文引用关系分析
- 批注视图与 Word 批注的一致性
